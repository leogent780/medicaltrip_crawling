# 네이버 지도 에스테틱 크롤러

지역명 + 키워드(기본 "에스테틱")로 네이버 지도를 검색해서, 나오는 업체를 훑고
주소/전화번호/인스타그램/카카오톡채널/홈페이지/첫방문이벤트를 모아 엑셀로 저장한다.

## 설치

```bash
cd crawler
pip install -r requirements.txt
playwright install chromium
```

## 실행

```bash
python naver_esthetic_crawler.py \
  --regions 명동 성수 홍대 강남 압구정 신사 용산 \
  --keyword 에스테틱 \
  --max-per-region 30 \
  --output seoul_esthetic_list.xlsx
```

- `--headless`: 브라우저 창을 띄우지 않고 실행 (기본은 창을 띄움 — 중간에 차단/캡차가
  뜨는지 눈으로 확인하기 편해서 기본값으로 뒀다)
- `--debug`: 검색 결과 목록 화면, 업체 상세 화면 스크린샷을 `debug/` 폴더에 저장. 결과가
  이상하거나 0건일 때 이 폴더를 보면 원인 파악이 쉽다.

지역 하나당 업체 수 x 몇 초씩 걸리니(상세 페이지 하나하나 열어서 정보를 긁기 때문에),
`--max-per-region`을 너무 크게 잡으면 오래 걸린다. 처음엔 5~10개로 테스트해보고
늘리는 걸 추천.

## 웹 화면으로 실행하기

터미널 명령어 대신 브라우저 화면에서 지역 체크박스와 개수를 입력하고 버튼 클릭으로
실행하고 싶으면:

```bash
python webapp.py
```

실행 후 브라우저에서 `http://127.0.0.1:5000` 접속. 주요 지역(명동/성수/홍대/강남/압구정/
신사/용산) 체크박스가 기본으로 떠 있고, 콤마로 구분해서 다른 지역도 추가 입력할 수 있다.
"크롤링 시작" 누르면 백그라운드에서 실행되고, 화면에 진행 로그가 실시간으로 쌓이다가
끝나면 "엑셀 다운로드" 버튼이 나타난다.

## 알아둘 점

- **선택자가 깨질 수 있음**: 네이버 지도 화면의 CSS 클래스명은 해시값이라 배포될 때마다
  바뀐다. 이 스크립트는 비교적 오래 유지돼온 구조적 id(`#searchIframe`, `#entryIframe`,
  `#_pcmap_list_scroll_container`)와 텍스트 패턴에 기대고 있어서, 언젠가 네이버 쪽 마크업이
  바뀌면 목록이 안 잡히거나 정보가 비어서 나올 수 있다. 그런 경우 `--debug`로 남긴
  스크린샷/HTML을 공유해주면 셀렉터를 바로 고칠 수 있다.
- **속도 제한**: `REQUEST_DELAY` (기본 1.5~3초 랜덤 대기)를 임의로 줄이지 말 것. 너무
  빠르게 대량 요청하면 네이버 쪽에서 접근을 차단할 수 있다.
- **첫방문 이벤트 탐지 범위**: 업체가 네이버 플레이스 "소식" 탭에 올린 게시글에서만
  "첫방문" 문구를 찾는다. 블로그 후기에 적힌 이벤트까지는 훑지 않는다(정확도가 떨어져서
  제외함) — 이런 경우는 빈 칸으로 남고, 필요하면 수기로 채워야 한다.
- **인스타그램/카카오톡채널**: 업체가 네이버 플레이스 상세정보에 직접 링크로 등록해둔
  경우에만 잡힌다. 등록 안 해둔 업체는 빈 칸으로 남는다 — 없는 걸 지어내지 않는다.
- 이 코드는 개인적인 리서치 목적의 소규모 수집을 전제로 만들었다. 짧은 시간에 대량으로
  돌리거나 상업적으로 재판매하는 용도로 쓰지 말 것.

## 참고

이 스크립트는 실제 네이버 서버에 접속해 테스트해보지 못한 상태로 작성됐다(작업 환경의
네트워크 정책상 map.naver.com 접속이 막혀 있었음). 로컬에서 처음 돌려보고 안 되는 부분이
있으면 알려주면 된다.
